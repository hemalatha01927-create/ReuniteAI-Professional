# ReuniteAI — Project Overview

**Project title:** ReuniteAI — AI-Assisted Missing Persons Case Management & Family Reconnection Platform  
**Project domain:** Artificial Intelligence, Web Development, Public Safety Technology, Information Systems

## Problem statement
Missing-person and found-person information can become fragmented across paper notes, informal messages and disconnected community channels. This makes it difficult to maintain consistent case details, protect reporter contact information, review incoming leads and keep families informed.

## Proposed solution
ReuniteAI provides one structured workflow for report submission, controlled publication with separate public-safe summaries and private case notes, private information sharing, family verification requests and reviewer-managed case updates. An explainable, non-biometric matching component helps prioritize pairs of reports for human assessment.

## Key objectives
1. Build a secure and usable missing/found case workflow.
2. Reduce unnecessary disclosure of sensitive contact information.
3. Make report publication subject to authorized review.
4. Prioritize possible links with transparent, explainable attributes.
5. Maintain notifications, case statuses and an audit trail.
6. Provide a professional responsive dashboard for members and case teams.

## User roles
- **Member:** submit reports, search active cases, submit private leads, request family verification, follow notifications.
- **Reviewer:** review reports, publish/reject cases, assess potential links, manage leads and verification requests.
- **Administrator:** all reviewer functions plus account-role management and audit history.

## AI-assisted matching logic
The matching engine assigns points for consistent city/state/area, approximate age, reported gender field, date proximity and overlapping descriptive keywords. It stores the reasons alongside the score. It does not compare face images, use biometric templates, infer identity or take automatic decisions. The threshold is a queue-prioritization mechanism and must be calibrated and evaluated using responsibly obtained, consented test data before any research claims are made.

## Suggested evaluation metrics
- Report submission completion rate
- Reviewer turnaround time
- Lead review time
- Precision/recall of potential-link ranking on consented, labeled synthetic or approved research data
- False-positive rate and reviewer override rate
- Accessibility/usability feedback
- Security test coverage and privacy-control verification

## Future research extensions
- Tamil and additional language interface support
- Geospatial distance ranking with appropriate location precision controls
- Explainable NLP for duplicate/near-duplicate report descriptions
- Encrypted document exchange for authorized institutions
- Formal integration only through approved government/institutional APIs and agreements
